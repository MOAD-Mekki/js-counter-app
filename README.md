# 🧮 JS Counter App

## 📌 Description

A simple and interactive counter application built using **HTML, CSS, and JavaScript**.
It allows users to increment, decrement, and reset a numerical value dynamically.

---

## 🚀 Features

* ➕ Increment the counter
* ➖ Decrement the counter
* 🔄 Reset to zero
* ⚡ Instant UI update (DOM manipulation)
* 💾 Save value using localStorage

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)
